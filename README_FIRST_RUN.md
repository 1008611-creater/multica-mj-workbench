# Multica Windows 中文创作工作台

## 先启动新版本

权威发行版本为 `2026.10.08.1`，安装包为 `Multica-Control-Console-2026.10.08.1.zip`。以公开软件仓库对应 tag 的 Release assets、SHA256 和发行记录为准。请解压到**新的独立目录**，双击 `Multica.exe`；也可使用 `Start-Multica.cmd`。本轮没有交付新的 Setup EXE，不要将历史安装器当作这一版安装器。

包内含独立 Python、桥接依赖、Node.js 和 Playwright；本机需 Microsoft Edge 和 Microsoft Edge WebView2 Runtime。桌面入口启动本地桥并打开中文工作台，默认地址 `http://127.0.0.1:8765/control`。另一套安装占用端口时软件会提示冲突，不会接管不同目录的桥。

## 顺手完成一轮创作

1. 在「准备创意」写提示词、任务名与画幅；高级参数按需展开。点「加入本轮任务」只是编辑草稿。
2. 批量导入 TXT、CSV、JSON 或 JSONL。支持行内编辑、批量参数、复制、模板及 Stylize × Chaos 组合实验。一次导入最多 2 MB、500 项。
3. 点「检查并保存批次」检查错误与重复并保存真实批次，**此时不生成、不扣费**。
4. 到「运行与批次」核对数量、参数和连接。开始或继续时须重新勾选本次费用确认。未授权状态保持待提交；软件启动和刷新不自动付费补位。
5. 在「图片工作区」查看真实成品、原图与回执，收藏、打标签、筛选、归档和并排比较。历史缺提示词显示「缺」，不凭空补齐。
6. 将有记录的成功输入复用到下一轮草稿；旧授权、运行状态不会继承。连接或技术诊断需要时才在「连接与设置」展开。

CSV 示例：

```csv
name,prompt,aspect,version,stylize,chaos,seed,raw
晨光森林,"A quiet forest at dawn, natural light",9:16,v7,300,10,42,true
```

高级参数填写在字段中，不在正文重复写 `--` 参数；Raw CSV 值只接受 true、false 或空。参数进入有效发送文本，平台是否采用仍需真实生成核验。

## 运行与异常

共享登录档案由浏览器锁保护，实际单路运行。独立档案支持本地最多三路调度，各自需由你登录；真实平台三路能力尚未验证。不要把界面并行上限当作平台承诺。

批次页可按「需要处理 / 排队 / 运行中 / 成品 / 已跳过」筛选，或搜索名称、提示词、作业号与报错；每种异常显示安全的下一步。筛选不会改变派发顺序。

「连接与设置 → 人工登录提醒」默认开启。检测到明确未提交的登录异常时暂停并弹窗，请手动登录后核查；不会自动继续生成。提醒需要工作台页面保持打开。

提交确认中、平台生成、下载和待核查分别显示。状态不明、费用不明或下载失败时先核查原作业与回执；不要重复提交。取消只停止后续派发，已提交的任务继续等待回执。断网不影响编辑已保存草稿。

Alt+1–4 切空间，Ctrl+Enter 打开检查，图片预览用左右键切图，Escape 关闭弹窗。键盘 Tab 在弹窗内循环。

## 保留本机数据

升级前需备份程序并核对任务、回执、图片、配置与浏览器档案。安装包中的 Install-Multica.cmd 提供安装入口；安装只合并程序，不迁移历史图片。已有安装升级以发行记录中的保留检查结果为准。

- 任务、进度和批次：`mj-automation/run/`。
- 图片与回执：`mj-automation/output/`、`archive/`、`receipts/`。
- 图库收藏、标签、归档：`mj-automation/run/library-annotations.json`。
- 登录浏览器档案：`runtime/browser-profile/`；内置页面档案：`runtime/webview-profile/`。
- 未提交草稿与模板保存在当前页面浏览器档案，换目录前请导出草稿；不要假定新包自动读取旧草稿。

程序需要修复时重新构建权威包；现有安装和数据目录独立保留。不要分享本机运行目录、登录档案或配置。分发 ZIP 不含账号档案、凭据、历史成品、任务或回执。

## 验证边界

本轮验证本地编辑、保存、真实历史图库、异常恢复及 Windows 包启动；没有登录或新付费生成。平台高级参数采用、真实三路、异机启动、覆盖安装升级和代码签名仍未验收。本地工作区的完整记录见 `docs/workbench-authority-2026-10-08.md`；公开发行说明见 GitHub Release。

## 图片筛选、比较与复用

图片工作区可同时筛选状态、批次、标签、模型和横竖方图，搜索多个词并按时间、收藏或名称排序。选择跨筛选保留；比较托盘最多四张，参数差异单独标记，可就地收藏或复用。批量选择最多一百张；复用只加入草稿，缺失信息须确认，不继承运行状态或费用授权。

在连接与设置填写默认原图目录与素材目录。默认原图目录供新批次使用，准备页面的保存位置可为某一批次单独覆盖；旧批次沿用原记录。选择图片并点击复制到素材目录，原始字节及来源 JSON 会放入指定目录的 multica-assets 子目录。再次复制会检查已有副本，冲突文件保留并报错。supent 需要填写其对应项目的实际素材位置；本地复制不代表远程上传或素材库数据库导入。
